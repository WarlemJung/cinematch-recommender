# 🎬 映画推薦システム

**映画推薦システム**へようこそ！このプロジェクトは、高度なデータ分析技術に基づいて映画を提案するために設計された堅牢な Python アプリケーションです。史上最高のヒット作を探している場合でも、お気に入りの映画に似た隠れた名作を探している場合でも、このシステムが対応します。

## 🚀 特徴

### 1. 📈 人口統計フィルタリング (トップチャート)
IMDB のトップ 250 と同様に、このシステムは **加重評価 (Weighted Rating - WR)** を計算することで最高の映画を特定します。平均評価と投票数の両方を考慮して、推奨される映画が人気があり、高く評価されていることを保証します。

*   **アルゴリズム**: IMDB 加重評価式。
*   **目標**: 普遍的に好まれる映画を推奨する。

### 2. 🧠 コンテンツベースのフィルタリング
特定のものを探していますか？この機能は、あなたが好きな特定の映画に似た映画を推奨します。映画の **あらすじ (overviews)** を分析して類似点を見つけます。

*   **アルゴリズム**: TF-IDF (Term Frequency-Inverse Document Frequency) & コサイン類似度。
*   **目標**: 似たようなストーリーやテーマを持つ映画を推奨する。

## 🛠️ 使用技術

*   **Python 3.13.7**: コアプログラミング言語。
*   **Pandas**: 効率的なデータ操作と分析のため。

## 📦 インストールとセットアップ

1.  **リポジトリのクローン** (またはファイルのダウンロード)。
2.  **必要なライブラリのインストール**:
    ターミナルを開いて実行します:

3.  **データセットのダウンロード**:

    [ここからデータセットをダウンロード](https://www.kaggle.com/datasets/rounakbanik/the-movies-dataset?resource=download&select=movies_metadata.csv)

## 🔍 コード概要

### `MovieRecommenderSystem` クラス

*   **`__init__`**: データをロードし、クリーニングして分析の準備をします。
*   **`get_demographic_recommendations`**: 各映画の加重スコアを計算し、上位の結果を返します。
*   **`compute_content_similarity`**: 映画の概要から TF-IDF 行列を構築し、コサイン類似度カーネルを計算します。
*   **`get_content_recommendations`**: 映画のタイトルを入力として受け取り、計算されたスコアに基づいて最も類似した映画のリストを返します。
