# 🎬 Система Рекомендации Фильмов

Добро пожаловать в **Систему Рекомендации Фильмов**! Это надежное приложение на Python, разработанное для предложения фильмов на основе передовых методов анализа данных. Ищете ли вы величайшие хиты всех времен или скрытую жемчужину, похожую на ваш любимый фильм, эта система поможет вам.

## 🚀 Особенности

### 1. 📈 Демографическая Фильтрация (Топ Чартов)
Подобно Топ-250 IMDB, эта система определяет лучшие фильмы, рассчитывая **Взвешенный Рейтинг (Weighted Rating - WR)**. Она учитывает как средний рейтинг, так и количество голосов, чтобы гарантировать, что рекомендуемые фильмы являются популярными и высоко оцененными.

*   **Алгоритм**: Формула взвешенного рейтинга IMDB.
*   **Цель**: Рекомендовать фильмы, которые нравятся всем.

### 2. 🧠 Фильтрация на Основе Контента
Ищете что-то конкретное? Эта функция рекомендует фильмы, похожие на определенный фильм, который вам нравится. Она анализирует **краткие содержания сюжета (overviews)** фильмов, чтобы найти сходства.

*   **Алгоритм**: TF-IDF (Term Frequency-Inverse Document Frequency) и Косинусное Сходство.
*   **Цель**: Рекомендовать фильмы с похожими сюжетами и темами.

## 🔍 Обзор Кода

### Класс `MovieRecommenderSystem`

*   **`__init__`**: Загружает данные, очищает их и подготавливает к анализу.
*   **`get_demographic_recommendations`**: Рассчитывает взвешенный балл для каждого фильма и возвращает лучшие результаты.
*   **`compute_content_similarity`**: Строит матрицу TF-IDF из описаний фильмов и вычисляет ядро косинусного сходства.
*   **`get_content_recommendations`**: Принимает название фильма в качестве входных данных и возвращает список наиболее похожих фильмов на основе вычисленных баллов.
